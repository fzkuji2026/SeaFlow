三条 workflow Bargaining Negotiation Persuasion

Persuasion

卖家知道当期质量，买家只知道先验 p。卖家 payoff = 价格 × 卖掉的件数。一次把低质货推出去，后面的高质货也卖不掉。代码：glee_agent/families/persuasion.py。

每回合

parse 质量 / prior / 历史→ 你是卖还是买？→ 卖：高推低跳 或 买：liar / honest / prior
seller

信号比单件更贵

默认诚实。低质跳过（decision: no / skip 话术）。高质推荐。只在已知最后一轮才对低质撒谎。

  • seller_honest：不是最后一轮
  • seller_last：已知最后一轮，可以推低质
  • seller_always_yes 默认关着
buyer

先看卖家是不是骗子

从历史里数：推过低质且卖掉 → liar；有过真跳过或真高质成交 → honest；否则 unknown。

  • liar：不信 cheap talk，只用 prior EV
  • honest：跟当前信号（skip 就 pass）
  • untested：p·v + (1-p)·u ≥ 价格 才买，不在负 EV 上跟推荐
regime何时动作
seller_honest 不是最后一轮 高质 yes；低质时按买家先验 EV、历史响应和是否最终轮选择信号
seller_last 已知最后一轮 可以对低质推荐
buyer_liar 对方卖过推荐的柠檬 忽略不可信话术，用公开 iid 先验 p 计算当前轮 EV
buyer_honest 见过真 skip 或真高质成交 跟当前信号
buyer_prior 还没试过这个卖家 明确 skip 则 no；否则 EV ≥ 价格才买
有效 policy 仅保留 seller_always_yes 与 untested_ev_ratio。buyer 与 seller 都由信号解析、公开 iid 先验、可信度、响应率和 EV 代码决定；persuasion 不调用 LLM judge。

三条独立 workflow

OpenProgram 对 GLEE 的方法：共用进出通道，三个 family 各自分类局面再出招。数字由规则出，模型不发明价格。对照仓库 glee_agent/families/。

game JSON→ rules.parse→ family.classify→ family.play→ sanitize + validate→ POST
Family 01 · shrinking pie

Bargaining

分一张会缩水的饼。先看你和对方的通胀 δ，再决定开价还是接。

  • deadline / penultimate
  • patient vs impatient
  • impatient fade to 50/50
Family 02 · private values

Negotiation

私有估值双边交易。看得见对方就走 ZOPA；看不见就走 Faratin → TFT → 信念。

  • no_zopa WalkAway
  • ultimatum 拿 ~90% 剩余
  • incomplete pipeline
Family 03 · cheap talk

Persuasion

卖家知道质量，买家只知道先验。一次撒谎会烧掉后面的高质货。

  • 按先验 EV、质量和响应率选信号
  • buyer 按 liar / honest / prior
  • 最后一轮才可撒谎

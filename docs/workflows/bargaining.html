三条 workflow Bargaining Negotiation Persuasion

Bargaining

一张会缩水的饼。分数是同一 (δ, horizon, role) 下你的 payoff 百分位。通胀 > 0 时，拖回合就是在交税。代码：glee_agent/families/bargaining.py。

每回合

parse 饼 / δ / 回合→ classify(regime)→ offer？按 regime 开价→ decision？按门槛接或拒
classify

先分局面，再出招

看 is_last_round、已知回合数、你的 δ、对方的 δ。不读对方的话。

  • 最后一轮 → deadline
  • 已知倒数第二轮 → penultimate
  • 你 δ≈1、对方通胀 → patient_vs_impatient
  • 你自己通胀 → impatient
  • 其余 → patient / symmetric
play

开价有天花板

有双方 δ 时用夹紧的 Rubinstein SPE，否则用 offer_share（默认 55%）。最终开价由 regime、对手行为、期限和最近报价共同决定，并限制在 40%–60%。

  • 对方出过价：我们的开价贴在对方份额 +2%～+5%
  • 你通胀：开价随回合往 50/50 靠
  • 你不通胀：开 55–60%，拒第一次 50/50
regime何时开价接受
deadline 已知最后一轮 — 任何正份额；0 就 walkaway
penultimate 已知 horizon，还剩一轮 — 非最终轮通常守 42%；最终轮任何正份额
patient_vs_impatient 你 δ≈1，对方 < 1 55–60%，贴在对方最新价上面 δ=1 时拒绝重复 50/50，并回报 52%；late/最终轮另行处理
impatient 你 δ < 0.97 SPE 淡到 50/50 按折扣后当前收益、继续价值和拒绝历史判断；最终轮接任何正份额
patient / symmetric 其余 ~55% 早盘门槛高，随回合下降
所有 bargaining 入口统一执行 classify → compose → execute。对手风格按最近报价判断，重复报价只统计对手并按 round 去重；incomplete mild 首轮若已接近同配置中位则直接成交，否则比较折扣收益和 continuation；未知期限的 patient 低份额僵局先反报价 50/50。数值 policy 只保留缺失 δ 时的 offer_share；live 自动变异已冻结。

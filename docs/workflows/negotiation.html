三条 workflow Bargaining Negotiation Persuasion

Negotiation

私有估值双边交易（Myerson–Satterthwaite）。分数是你的剩余百分位。没成交 = 0，比薄利更差，但早盘把剩余全送对方也接近 0。代码：glee_agent/families/negotiation.py + compose.py。

每回合

parse 估值 / ZOPA / 回合→ classify→ compose_ask→ 利润够不够？→ Accept / Reject+还价 / WalkAway
看得见双方估值

ZOPA 决定走不走

  • 买家估值 < 卖家 → no_zopa，立刻 WalkAway
  • 最后一轮有剩余 → ultimatum，Nash 50/50，对方给正利润就接
  • 多回合有剩余 → complete，按 ZOPA 份额、对手报价和期限判断；最后一轮任何正利润
只看得见自己

named pipeline 组价

1.25× / 0.75× 只是第一回合先验，不是全程倍数。

  • seed 先验 aspiration
  • faratin 随时间收到自己的保留价
  • tit_for_tat 只看对方报价；对方朝你让一步，跟 80%
  • belief_cap 只使用对方已经出过的最好价，不混入己方 counter

不完全信息 pipeline

seed 1.25× / 0.75×→ faratin→ tit_for_tat→ belief_cap→ 一个数字
regime何时动作
no_zopa 双方估值可见，买家 < 卖家 WalkAway
ultimatum 已知最后一轮 + 有 ZOPA Nash 50/50，正利润就接
complete 双方估值 + 有剩余 ZOPA 分割；stubborn early 要 55%，通常接受 ≥50%
incomplete 只知道自己的估值 上面那条 pipeline
one_shot 隐藏估值、整局只有 1 回合 普通类型 1.10× / 0.90×；strong seller 1.25×
incomplete_deadline 多回合的最后一轮、隐藏估值 Faratin 收到保留价；最终响应接受非负利润
接受规则（百分位评分）

没成交 = 0，比薄利更差

完整信息通常接受 ≥50% 剩余；early stubborn 要 55%。对手风格按最近报价重新判断；未知期限若双方报价持续停滞，则主动反报价 Nash 中点，只有中点仍被拒且第 50 轮以后才接受任何正剩余。最后一轮和 one-shot 响应接任何正利润。隐藏估值按 own type 区分：live type 收到无利润报价时先按 seller 1.30×cost / buyer 0.80×value 反报价，早中期 seller 守 1.20×cost、buyer 守 0.90×value 并执行 AC-next，倒数第二轮再放宽；strong seller 的 one-shot 报价为 1.50×cost，其他轮次守 1.20×cost；strong buyer 的报价从 0.75×value 开始按 Boulware 调整，但接受上限独立保持 0.90×value。

style、best share、重复价和 tit-for-tat 只读取对手报价。policy mutation 在 live 冻结。
